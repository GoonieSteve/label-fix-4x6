1. Extract the entire ZIP. Do not launch from inside the ZIP.
2. Double-click LabelFix4x6.exe. Keep all bundled DLLs and files alongside it.
3. Select a PDF, convert, and check the printed barcode before shipping.
4. For automatic printing, install SumatraPDF separately and enable printing inside LabelFix.
5. If Windows Defender quarantines the app, do NOT disable security.
   Record the threat name and file in Windows Security > Protection History.
   Contact Keys Web & IT and consider Microsoft's software-developer submission portal.
